网络安全工具使用、Agent脚本编写与攻击工具全面总结

一、网络安全常用工具及命令

1. 基础网络诊断命令

命令用途常用参数
ping检测网络连通性（ICMP协议）ping -t 目标IP（持续ping）、ping -l size IP（指定包大小）
ipconfig / ifconfig查看/配置网络接口信息ipconfig /all（详细信息）、ipconfig /flushdns（清除DNS缓存）
arp查看/修改ARP缓存表arp -a（查看所有条目）、arp -d（删除条目）
tracert / traceroute追踪数据包到达目标的路径tracert -d IP（不解析主机名）
netstat查看网络连接、端口、路由表netstat -ano（显示所有连接和PID）、netstat -anp tcp
nslookup / digDNS查询nslookup 域名、dig 域名 A
route查看/修改路由表route print（显示路由表）
ss (Linux)获取网络套接字详细信息ss -tulnp（监听端口及进程）

5. Agent 脚本编写最佳实践

原则说明
超时控制所有 subprocess.run() 必须设置 timeout，防止扫描工具卡死
沙箱隔离在 Docker / VM 中运行Agent，避免工具误操作宿主机
输出解析使用 -oX/-oJ 等参数输出结构化数据（XML/JSON），便于Agent解析
错误处理捕获 subprocess.TimeoutExpired、FileNotFoundError 等异常
权限最小化Agent使用的账户应仅有执行必要工具的权限
审计日志记录所有工具调用和输出，便于合规审计
