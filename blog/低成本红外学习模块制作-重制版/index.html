低成本红外学习模块制作

基于原版教程，经浏览器交叉验证后修订。总成本约 8～15 元（视开发板选择），可在电脑串口监视器中查看红外 RAW 脉冲时序，适合空调等长码遥控学习。

浏览器验证摘要（重点：硬件接线）

以下资料已通过浏览器 / 网页抓取核对，Arduino 侧接线（5V / GND / D11）与原教程一致，可放心使用：

原教程需补充的勘误

  1. 引脚左右顺序不能死记：原版写「VCC(中) / GND(右) / OUT(左)」仅适用于部分裸露 VS1838B 封装；市面更常见的是 KY-022 / HW-490 / Keyes 小板，丝印为 S / 中间(VCC) / –(GND)，且部分克隆版会把 S 与 – 对调。
  2. 标准数据手册引脚顺序另有版本：部分 VS1838B 规格书写为「OUT – GND – VCC」（面朝接收窗、引脚朝下、从左到右），中间脚是 GND 而非 VCC。务必以板子丝印为准，禁止仅凭位置接线。
  3. D11 可用但非必须：D2、D3、D11 等任意数字口均可；现代 IRremote 4.x 不强制中断引脚。选 D11 与 Keyes / KY-022 官方例程保持一致，方便抄代码。
  4. 供电电压：Arduino UNO / Nano 的 5V 引脚供电即可（模块支持 2.7～5.5V）；ESP32 等 3.3V 板请改接 3.3V。

2.2 标准接线表（Arduino UNO / Nano 通用）

2.3 接线示意图

2.4 接线操作步骤

  1. 断电状态下完成接线，最后再接 USB。
  2. 模块 VCC → Arduino 5V；GND → GND；S/OUT → D11。
  3. 接收窗朝向遥控器，避免阳光直射（环境红外干扰会导致乱码）。
  4. 上传代码后，打开串口监视器 115200 波特率，对准模块按遥控器测试。

2.5 接线自检与排错

现象可能原因处理办法
完全无输出S 与 GND 接反（克隆板常见）断电，对调 S 与 – 两根线
乱码 / UNKNOWN 刷屏阳光直射、灯光干扰遮挡环境光，缩短距离重试
上传失败CH340 驱动未装安装驱动，换 USB 口或数据线
板子发烫VCC/GND 反接立即断电，检查丝印
想确认遥控器在发射手机相机对准遥控发射窗按下按键应看到紫白色闪烁

2.6 进阶说明（可选）

  • 裸露 VS1838B（无 PCB）有时需外接 10 kΩ 上拉电阻（OUT 与 VCC 之间）；KY-022 小板已集成，无需外加。
  • 后续若要发射红外，可另加 IR LED + 100 Ω 限流电阻到 D3，用 IrSender.sendRaw() 重放。

三、Arduino 代码（输出 RAW 脉冲时序）

在 Arduino IDE 安装库：工具 → 管理库 → 搜索 IRremote（作者 Armin Joachimsmeyer，选 4.x 版本）。

上传后打开串口监视器（115200 波特率），对准接收头按遥控器，即可看到协议类型 + RAW 微秒数组。

四、关于「学习 / 重发」

  • 只看 RAW 码：串口输出的微秒数组即为 raw timing，复制保存即可用于后续重放或分析。
  • 重发（发射）：加 IR LED（+ 100 Ω 限流电阻）接 D3，调用 IrSender.sendRaw(rawData, rawLen, 38) 原样发出。空调等长码可能超出默认 buffer，需在库中增大 RAW_BUFFER_LENGTH。

五、更省事的替代方案（无 Arduino）

购买成品万能红外学习模块（如 IR05F / XM-IR01），通过 USB-TTL（CH340） 接电脑串口助手，发送学习指令后模块返回十六进制编码帧。

对比项Arduino + KY-022成品学习模块
成本≈ 8～15 元≈ 15～30 元
输出格式微秒级 RAW 数组模块私有十六进制帧
灵活性高，可自定义处理低，依赖模块协议
适合场景空调长码、协议分析快速学码、嵌入式集成
