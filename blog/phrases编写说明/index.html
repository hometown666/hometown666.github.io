Phrases YAML 编写说明

本文档说明如何为「Learn English Phrases」页面编写词组数据文件。数据存放在 source/_data/phrases/ 目录，由主题标签 {% phrases %} 读取并渲染为可折叠的词组卡片。

目录结构

命名规则： 每个文件对应一个词组关键词首字母（小写）。例如 adapt oneself to sth 的关键词是 adapt，写入 a.yml；bump into sb/sth 的关键词是 bump，写入 b.yml。

同一文件内可包含任意多条词组，构建时会按关键词字母序、再按按钮全文排序。

在文章中使用

在 Markdown 文章中通过 Hexo 标签引入：

写法 效果
{% phrases %} 加载 phrases/ 下全部 .yml
{% phrases a %} 仅加载 a.yml
{% phrases a,b,i %} 加载多个文件（逗号或空格分隔均可）

参考：source/_posts/English Phrases.md

顶层结构

每个 .yml 文件是一个数组，数组中每一项代表一个词组条目：

字段一览

字段 必填 说明
id 推荐 唯一标识，用于 data-phrase-id 属性，建议用 kebab-case
button 是 折叠按钮上显示的文字，由多个片段组成
senses 是 释义列表，一条词组可含多个义项
keyword 否 自定义排序用关键词；省略时取 button 中 word: true 的片段

button — 按钮文字

button 是片段数组，按顺序拼接成按钮上的可见文字。

普通片段

属性 说明
text 显示文字
word 设为 true 时，该片段用 <word> 标签包裹（关键词高亮样式）
sup 上标文字，用于区分同一按钮下的多个义项编号

word: true 的作用：

  1. 按钮上突出显示关键词（如 adapt、bump）
  2. 作为默认排序关键词（除非设置了 keyword 字段）

senses — 义项

每个 sense 代表一个词性/含义，展开折叠块后依次显示。

基本字段

字段 必填 说明

posHtml 否 词性 HTML，与 pos 二选一；用于下标等，如 n<sub>1</sub>.

YAML 编写注意事项

  1. 含特殊字符的 text 请加引号
    空格、冒号、括号、# 等可能导致 YAML 解析错误，建议写成 " into sb/sth"、"(to "。

  2. 缩进使用空格，不要用 Tab
    统一 2 空格缩进，与现有文件保持一致。

  3. id 命名建议
    使用小写英文 + 连字符，如 adapt-oneself-to-sth、bump-into-sb-sth，便于识别且避免重复。

  4. 修改后需重新生成
    数据在 Hexo 构建时读取并缓存；修改 yml 后执行 hexo clean && hexo g（或 hexo s）才能看到更新。

  5. 文件为空或不存在
    若指定字母的文件不存在或无有效条目，页面会输出 HTML 注释 <!-- phrases: no data (a) -->，不会报错。
