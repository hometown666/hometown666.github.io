控制端：外出设备接入指南

控制端是在外面用来连家里 Win11 的设备。被控端先按 remote_controled 配好，控制端再按下面方案接入。

前提：所有控制端都用同一个 Tailscale 账号登录，和被控端出现在同一 mesh 里。被控端的 Tailscale IP（100.x.x.x）是连接地址，下文用 100.xxx.xxx.xxx 占位，换成你家的真实 IP。

公共步骤：Tailscale 组网

每台控制端先装 Tailscale、同账号登录，确认能在 Tailscale 管理后台看到家里的 Win11。

平台 安装方式
Windows 官网下载 Windows 版 → 登录
Android Google Play 搜 Tailscale → 登录

连上后可用 ping 100.xxx.xxx.xxx（Windows）或在 Tailscale App 里点机器名，确认和被控端是 Direct 直连（NAT 打不通时会走 DERP 中继，也能用但稍慢）。

4. 通过 SSH 与 Agent 对话（推荐，无需 Worker）

被控端完成 remote_controled §7（装 CLI + agent login）即可。全程走 Tailscale + SSH，不需要 agent worker start，也不需要 cursor.com/agents。

方式 A：Cursor Remote-SSH + Agent 面板（笔记本图形交互）

  1. 按上文 §3 连上 home-win，打开被控端上的项目文件夹
  2. Ctrl+L 或 Agent 侧栏 → 直接和 Agent 对话
  3. Agent 改文件、跑终端都在被控端执行，体验和本地 Cursor 基本一致

部分旧版 Cursor 在 Remote-SSH 下 Agent 可能报 agent execution provider did not respond in time。控制端和被控端都更到最新；仍失败就改用下面的方式 B（终端 agent），通常更稳。

方案二：Android 手机（随身看输出、跑小指令）

适合在外面掏手机快速看 Agent 有没有跑崩、执行几条命令。不适合写大段代码。

1. Tailscale

Google Play 安装 Tailscale → 用和被控端相同的账号登录 → 确认设备列表里能看到家里 Win11。

手机流量/Wi‑Fi 切换时 Tailscale 会自动重连，一般不用手动维护。

2. Termius（推荐 SSH 客户端）

  1. Play 商店装 Termius
  2. 新建 Host：
    • Label：home-win
    • Address：100.xxx.xxx.xxx（被控端 Tailscale IP）
    • Port：22
    • Username：dev（被控端本地账户）
    • Auth：密码；或把 ed25519 私钥导入 Termius（和 Windows 上生成的 key 可共用）
  3. 保存后点连接，即可 ls、tail -f、跑 agent、或 tmux attach 续 Agent 会话

Termius 里也能和 Agent 对话：SSH 进去后执行 agent（交互）或 agent -p "你的任务"（一次性）。屏幕小，适合盯进度、发短指令；大段开发还是笔记本 Remote-SSH 更舒服。长跑任务务必配合 tmux，见上文 §4 方式 B。

Termius 导入密钥（Android）：

  • 把 id_ed25519_home 私钥文件拷到手机（或通过 Termius 的 Import Key）
  • Host 里 Auth 选 Key，选中该密钥

3. 其他 Android SSH 客户端（备选）

App 说明
JuiceSSH 免费、轻量，Host + 密钥配置和 Termius 类似
ConnectBot 开源，适合只要纯 SSH 的用户

配置项都一样：Address = Tailscale IP，Port 22，User = dev。

4. Android 上看完整桌面（可选）

手机小屏看桌面体验一般，应急可以：

方案 Android 端
Parsec Play 装 Parsec 客户端，同账号登录
Chrome Remote Desktop 装 Google 远程桌面 App，或在 Chrome 里打开

和被控端 Parsec / CRD 主机端配对使用。

控制端场景对照

场景 Windows 控制端 Android 控制端
远程写代码 + Agent 面板 Cursor Remote-SSH 不推荐（屏幕太小）
Agent 终端对话 / 脚本 ssh home-win → agent / agent -p Termius → agent 或 tmux attach

组网 Tailscale Windows Tailscale Android

控制端常见问题

连不上先 ping Tailscale IP：两设备是否都在线、是否同一 Tailscale 账号。

SSH 密码一直 fail：被控端是否用了 Microsoft 账号且无本地密码？见 remote_controled §2。

公钥配置了仍要密码：被控端 authorized_keys 权限是否修过？sshd 是否重启？

Tailscale 显示 Relay 而非 Direct：NAT 打洞失败，走中继仍可用，速度会降一些；换网络或等一会儿有时会变 Direct。

Microsoft 账号 / 本地账户：SSH 的 User 填被控端本地用户名（如 dev），不是邮箱。

agent 命令找不到：被控端是否装了 CLI 且 PATH 含 %USERPROFILE%\.local\bin？见 remote_controled §7。

Remote-SSH Agent 超时：先升级 Cursor；仍失败就 ssh home-win 跑终端 agent，见 §4 方式 B。
