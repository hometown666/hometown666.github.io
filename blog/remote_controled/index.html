被控端：家里 Win11 配置指南

家里这台 Win11 是被远程控制的机器。按顺序做完下面几步，外出设备才能通过 Tailscale 连进来敲命令或开桌面。

1. 装 OpenSSH Server

GUI 路径（最稳）：

设置 → 系统 → 可选功能 → 添加功能，搜 OpenSSH Server 装上（Client 顺手也装）。

PowerShell（管理员）等效：

安装时 Windows 会自动建一条防火墙入站规则 OpenSSH-Server-In-TCP 放行 TCP 22。如果 Get-NetFirewallRule -Name "*ssh*" 看不到，手动补一条：

Win11 可选功能装不上的坑：系统没更到最新会卡住，先 Windows Update → 检查更新 → 重启 再装；公司域/WSUS 环境也可能拦，需要临时关 UseWUServer。

2. 搞一个能 SSH 登录的本地账户（关键）

如果 Win11 登的是 Microsoft 账号（邮箱那种），默认没有本地密码，SSH 输密码会一直 fail。两种解法二选一：

  • 解法 A：设置 → 账户 → 您的信息 → 改为使用本地账户登录，设一个本地密码，之后 SSH 就用 电脑名\用户名 + 这个密码登。
  • 解法 B：新建一个专用开发账户 net user dev 密码 /add，net localgroup administrators dev /add，以后 SSH 全用这个。

别直接用 Administrator 当 SSH 入口，权限太大。

3. 电源 & 睡眠别让它断网

  • 设置 → 系统 → 电源 → 屏幕和睡眠：插电时永不睡眠（可以关屏）
  • 网卡属性里把「允许计算机关闭此设备以节约电源」取消勾选，防止 Tailscale 掉线

家里 Win11 睡了 = 全断：Tailscale + SSH 都靠机器醒着，电源策略先看牢。

4. 装 Tailscale 并开启无人值守

  1. 官网下 Tailscale Windows 版装上，浏览器登录你的账号
  2. 系统托盘 → Tailscale → Run unattended（无人值守） 勾上 → 这样重启后没登桌面也能连回来
  3. 命令行 tailscale ip 记下这台机器的 Tailscale IP（格式 100.x.x.x），告诉控制端用这个地址连

Tailscale 免费版：个人 100 台设备、速度够用，不限制流量。运营商如果是 CGNAT 也无所谓，Tailscale 不依赖公网 IP。

6. 完整桌面远程（可选）

SSH 只能敲命令。如果控制端需要看浏览器、点 GUI，在被控端额外装：

方案 被控端要装的 特点
Parsec Parsec 主机端 低延迟，但锁屏/login screen 有限制，休眠/resume 要配合
Chrome Remote Desktop Chrome 远程桌面主机 完全无人值守也能连，延迟略高但不挑场景

两个可以同时装，互为备份。控制端对应装客户端即可，详见 remote_controling。
